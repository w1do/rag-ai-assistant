# Navigation — ManuFlex

## Header Structure
- **Layout:** Horizontal top bar with three main zones.
  1. **Left:** Company Logo (Brand Wordmark).
  2. **Center:** Primary Navigation Links (Regular weight, `DM Sans`).
  3. **Right:** Action Area (Sign In button, search, or language switcher).

## Visual Style
- **Background:** Sticky header with transparent base and glassmorphic blur effect on scroll.
- **Button Style:** "Sign In" is typically an outlined pill button (`Secondary` style with `--radius-full`).
- **Typography:** Navigation links use 15px `DM Sans` with medium tracking.

## Mobile Navigation
- **Trigger:** Hamburger menu icon (Lucide stroke style).
- **Overlay:** Full-screen or slide-out menu with stacked links.
- **CTA:** Primary action button often remains visible or moves to the top of the mobile list.

## Footer (Implicit)
- **Layout:** Multi-column grid.
- **Content:** Large brand wordmark as a background element, column-based links for services, legal, and contact.
- **Contrast:** High contrast (e.g., dark background with white text).
