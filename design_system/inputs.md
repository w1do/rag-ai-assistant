# Inputs — ManuFlex

## Input Specifications

| Property | Value |
|----------|-------|
| **Shape** | Rounded rectangle |
| **Height** | ~44px |
| **Radius** | 10px (`--radius-md`) |
| **Border** | 1px neutral border |
| **Font** | `DM Sans`, 15px (`--text-body`) |

## Themed Styles

### Light Mode
- **Background:** `#FFFFFF` or very light gray.
- **Border Color:** `#E5E5E5` (Subtle neutral).
- **Text Color:** `#111111`.
- **Placeholder:** `#5C5C5C` (Secondary text).

### Dark Mode
- **Background:** `#151B27` (Dark Surface).
- **Border Color:** `#2A3342` (Deep navy accent).
- **Text Color:** `#F0F0F0`.
- **Placeholder:** `#8A8FA0`.

## Interactive States
- **Focus:** 1px border shift to Brand Color (`#C8A645`) or subtle glow.
- **Error:** 1px border change to Semantic Error (`#D93025`).
- **Disabled:** Reduced opacity (40%), background tint.
