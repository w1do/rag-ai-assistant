# Frontend Layout Design — NeuralFlow (AI & RAG Edition)

## Overview
Дизайн публичного сайта NeuralFlow адаптирует индустриальную мощь ManuFlex под мир искусственного интеллекта и RAG-систем. Это эстетика "прозрачного интеллекта": глубокие темные пространства, светящиеся узлы данных и четкая иерархия потоков информации.

## Background Palette & Atmosphere
- **Primary Background:** `#0C1019` (Deep Navy Charcoal).
- **Secondary Background:** `#151B27` (Neural Surface).
- **Atmosphere:** Использование "Neural Blue" градиентов и эффектов свечения (glow), имитирующих работу нейронных сетей.

## Layout Sections

### 1. The Neural Hero (Interactive Core)
- **Background Layer:** Текст "INTELLIGENCE" в стиле `DM Serif Display` (opacity 3%), сквозь который проходят анимированные линии связей (nodes).
- **Main Content:** Левая сторона — заголовок "Умные ассистенты с индустриальной точностью". Правая сторона — интерактивный 3D-объект "Ядро знаний", который пульсирует в такт "обработке данных".
- **Glass Stat Overlays:** Плавающие показатели: "Tokens/sec", "Knowledge Base Size", "Context Accuracy".
- **Animation:** Эффект "Neural Pulse" — по линиям связи пробегают световые импульсы.

### 2. RAG Flow Architecture (Nested Pipeline)
- **Concept:** Визуализация пути данных от документа до ответа.
- **Design:** Последовательность вложенных блоков:
    - **Data Input:** Блок с иконками документов.
    - **Vectorization:** Вложенный блок с анимацией "превращения текста в код".
    - **Retrieval Core:** Центральный элемент с эффектом `Dark Surface Glass`.
    - **LLM Synthesis:** Финальный блок выдачи ответа.
- **Interaction:** При клике на этап пайплайна, он расширяется, показывая технические детали (Top-K, Similarity Threshold).

### 3. Agent Ecosystem Showcase
- **Grid:** Сетка карточек ассистентов.
- **Card Design:** 
    - Внешний контур с мягким золотым свечением.
    - Вложенный блок с "Характером ассистента" (Progress bars для Creativity, Logic, Speed).
    - **Interaction:** При ховере карточка "оживает" — появляется аватар бота с анимацией дыхания.
- **Typography:** Имена ботов — `DM Serif Display`, характеристики — `DM Sans Mono` для технологичного вида.

### 4. Interactive Learning Roadmap (RAG Training)
- **Style:** Вертикальная линия времени (Knowledge Growth).
- **Design:** Каждый этап обучения — это вложенный блок с "индикатором зрелости" ИИ.
- **Visuals:** Использование градиентов от белого к Brand Gold для обозначения "ценности знаний".

## Animations & Transitions
- **Knowledge Pulse:** Мягкая пульсация границ блоков, которые содержат "активные данные".
- **Data Streaming:** Эффект летящих частиц между секциями, направляющий взгляд пользователя вниз по воронке знаний.
- **Lock-in Reveal:** Текст и блоки фиксируются с эффектом "магнитного притяжения" при скролле.

## Visual Elements
- **Icons:** Lucide (Brain, Database, Zap, Cpu), цвет Brand Gold (#C8A645).
- **Graphic Elements:** Схемы нейронных связей, изометрические блоки серверов, "облака" векторов.
