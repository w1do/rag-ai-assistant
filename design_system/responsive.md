# Responsive Strategy — ManuFlex

## Breakpoints
- **Mobile:** ≤ 767px
- **Tablet:** 768px - 1023px
- **Desktop:** ≥ 1024px

## Grid & Margins
- **Desktop:** 12-column grid, 80px side margins.
- **Mobile:** Single column layout, 16px-20px side margins.

## Typography Scaling
| Level | Desktop | Mobile |
|-------|---------|--------|
| `Display` | 56px | 32px |
| `Title` | 40px | 26px |
| `Body` | 15px | 15px |

## Component Behavior

### Cards
- **Desktop:** Multi-column (3-4 columns).
- **Mobile:** Stacked vertically, full viewport width.

### Buttons
- **Desktop:** Fixed or content-based width.
- **Mobile:** Often expand to **100% width** for better touch targets.

### Sections
- **Desktop:** Asymmetric split layouts (Side-by-side).
- **Mobile:** Elements stack vertically (Image top, text bottom).
- **Vertical Gaps:** Section spacing reduces from 80px (XL) to ~40px (Large) on mobile.

## Navigation
- Switch from horizontal bar to **Hamburger Menu** on screens < 1024px.
