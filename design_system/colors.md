### Основные цвета:
| Назначение | Цвет |
|------------|------|
| Primary (основной) | Синий (`#...`) |
| Secondary (вторичный) | Черный (`#...`) |
| Background | Белый (`#FFFFFF`) |
| Тени | `#F5F5F5` |

### Правила:
- Не использовать более 3 основных цветов на одном экране
- Для акцентов использовать primary цвет
- Текст должен иметь достаточный контраст
