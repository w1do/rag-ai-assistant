### Типы кнопок:

| Тип | Описание | Стиль |
|-----|----------|-------|
| **outline** | Контурная | Черная обводка, прозрачный фон |
| **filled** | Заливная | Синяя заливка, белый текст |
| **icon** | С иконкой | Черная, иконка справа |
| **loader** | С загрузкой | Outline + синий лоадер |

### Состояния:
- Default
- Hover
- Active
- Disabled
