# Summary

## Текущее состояние
Проект представляет собой RAG-систему на базе Laravel 13.
Внедрена стабильная система парсинга веб-страниц через Firecrawl с поддержкой прокси и механизмом повторных попыток.

## Ключевые изменения
- Реализована кастомизация ассистента: добавлены поля `style`, `brand_name`, `phone`, `social` и `fallback`.
- Внедрены предопределенные стили общения: коммерческий, деловой, грубый и позитивный.
- Обновлена логика формирования системного промпта в `AskAssistantQuery` для учета индивидуальных настроек ассистента.
- Реализована логика `fallback`: теперь ассистент использует заданное сообщение, если не может найти ответ в контексте.
- Исправлена критическая ошибка `Class "Qdrant\Models\Request\Points\BatchIdSelector" not found`, возникавшая при удалении сайтов или знаний.
- Повышена надежность индексации данных в Qdrant путем добавления механизма повторных попыток (retries) при сбоях сети.
- Исправлена логика обновления статусов: теперь статус "готово" устанавливается только после успешного завершения индексации в векторном хранилище.
- Исправлены критические ошибки в `VectorStoreManager`, связанные с использованием неверных имен классов клиента Qdrant.
- Реализована автоматическая очистка старых чанков в локальной БД при переиндексации данных, что предотвращает дублирование.
- Исправлена проблема, из-за которой `qdrant_id` не сохранялся в локальной базе данных, что создавало видимость отсутствия данных в Qdrant.
- Добавлена генерация детерминированных UUID для чанков на основе их типа источника, имени и номера чанка.
- Улучшено логирование процесса индексации: теперь логируется количество созданных чанков и длина полученного контента.
- Исправлена ошибка `Unknown named parameter $knowledgeId` при добавлении сайта, загрузке документов и аудио.
- Исправлена проблема с некорректными метаданными документов (пустой `hash` и `sourceType: "manual"`) при парсинге сайтов и транскрибации аудио.
- Вызовы `IndexAssistantDocumentsAction->execute` переведены на использование позиционных аргументов вместо именованных.
- Обновлен `WebParser` для работы с ротацией прокси.
- Добавлена логика `retries` (3 попытки) для HTTP-запросов.
- Интегрировано подробное логирование ошибок парсинга.
- Реализованы тесты для проверки отказоустойчивости парсера.
- Добавлена PHPDoc документация для ключевых классов действий (Actions).

## Vibe Coding
Код следует принципам DDD. Используются современные возможности Laravel (v11/v13) для работы с HTTP-клиентом.
Вектор развития: повышение надежности сбора данных для базы знаний RAG.
