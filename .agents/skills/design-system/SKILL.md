# Design System

Этот навык обеспечивает работу с дизайн-системой проекта. Все правила находятся в папке `design_system/`, главный (входной) файл — `design_system/DESIGN.md`. Все инструкции дизайн-системы являются **обязательными** к исполнению.

## When to Activate

Активируй этот навык всякий раз, когда:
- создаёшь новый UI-компонент, страницу или экран;
- изменяешь существующий интерфейс (цвета, шрифты, размеры, кнопки, карточки);
- проводишь ревью интерфейса на соответствие дизайн-системе;
- добавляешь компонент в UI-кит (`/ui-kits`).

Не жди, пока столкнёшься с проблемой — сверяйся с дизайн-системой заранее.

## Source of Truth

Перед началом работы прочитай главный файл и нужные разделы:

| Тема | Файл |
| --- | --- |
| Главный документ / правила / процесс | `design_system/DESIGN.md` |
| Интерфейс (общие правила) | `design_system/interface.md` |
| Цвета (палитра) | `design_system/colors.md` |
| Шрифты | `design_system/fonts.md` |
| Размеры / отступы | `design_system/sizes.md` |
| Кнопки | `design_system/buttons.md` |
| Карточки | `design_system/cards.md` |
| Компоненты | `design_system/components.md` |

Всегда открывай конкретный файл из таблицы перед тем, как применять или менять соответствующий элемент. Не полагайся на память — значения могут отличаться.

## Core Principles

- Соблюдать единообразие всех элементов.
- Использовать компонентный подход.
- Обеспечивать адаптивность под все устройства.
- Поддерживать доступность (accessibility).

## Workflow

### Реализация интерфейса
1. Получить макет/требования.
2. Сверить элементы с инструкциями из `design_system/`.
3. Реализовать через существующие компоненты.
4. Проверить по контрольному списку (ниже).
5. Передать на ревью.

### Новый компонент
1. Проверить, нет ли уже похожего компонента.
2. Создать папку компонента по принятой структуре.
3. Написать компонент с типами и стилями.
4. Добавить JSDoc-документацию.
5. Зарегистрировать в общем экспорте.
6. Отразить компонент на странице UI-кита (`/ui-kits`).

## Checklist (обязательно перед сдачей)

- [ ] Все цвета соответствуют `colors.md`.
- [ ] Все шрифты и размеры из `fonts.md` и `sizes.md`.
- [ ] Карточки имеют правильные тени, обводку и hover-эффекты (`cards.md`).
- [ ] Кнопки — одного из допустимых типов (`buttons.md`).
- [ ] Нет перегруженности контентом.
- [ ] Использованы бейджи для важной информации.
- [ ] Bento-карточки: изображение по центру, текст сероватый.
- [ ] Учтены состояния hover/active.
- [ ] Интерфейс адаптивен и доступен.

## Forbidden

- Использовать цвета вне палитры.
- Менять размеры шрифтов/отступов произвольно.
- Создавать новые типы кнопок.
- Перегружать карточки контентом.
- Игнорировать hover/active состояния.

## Notes

- При любых сомнениях обращайся к `design_system/DESIGN.md` и связанным файлам.
- Веди страницу со всеми UI-компонентами и их инструкциями: `/ui-kits`.
