# Лендинг BotSync

Документация по реализации главной страницы (Welcome Page) проекта.

## Обзор
Лендинг спроектирован как презентационная страница сервиса для обучения AI-ассистентов. Он демонстрирует ключевые возможности платформы, тарифные планы и предоставляет интерактивное демо.

## SEO Оптимизация
В июне 2026 года была проведена масштабная SEO-оптимизация страницы для максимального охвата целевой аудитории:
- **Мета-теги**: Обновлены `title`, `description` и `keywords` с упором на ключевые слова: "ии онлайн", "чат ии", "бот чат", "rag системы".
- **Заголовки**: Внедрены ключевые слова в H1 и H2 для улучшения индексации.
- **Контент**: Тексты секций адаптированы для более плотного вхождения поисковых запросов без потери читаемости.

## Структура страницы
1. **Hero-секция**: Заголовок с уникальным торговым предложением (УТП) и призывом к действию (CTA).
2. **Демо-чат**: Интерактивное поле ввода (под id 2) с подсказками для пользователя. Позволяет визуализировать работу обученного ассистента.
3. **Функциональные блоки**:
    - Обучение на сайтах конкурентов (URL-парсинг).
    - Обработка голосовых сообщений (транскрибация).
    - Анализ документов (PDF, Word, Excel).
4. **Интеграция и синхронизация (Data Sync)**: Описание возможностей подключения к внешним системам. Подробности в [docs/data_sync.md](data_sync.md):
    - CRM (Bitrix24, amoCRM).
    - Закрытые системы и личные кабинеты.
    - Автопулинг данных для регулярного обновления базы знаний.
5. **Технологический стек (Tech Stack)**: Слайдер с используемыми нейросетями и инструментами (Claude, GPT, Gemini, LlamaIndex и др.).
6. **Процесс настройки (Setup Process)**: Пошаговая инструкция из 4 этапов (Регистрация, Создание, Обучение, Интеграция).
7. **Кейсы использования (Use Cases)**: Карточки отраслей (ретейл, автосервисы, агентства и др.) с SEO-оптимизированным описанием.
8. **Тарифные планы**: Три варианта подписки (Пробный, Ежемесячный, Годовой) с детализацией преимуществ. Данные синхронизированы с разделом управления тарифами.
9. **FAQ**: Интерактивный аккордеон с 10 наиболее частыми вопросами об AI RAG, мониторинге конкурентов и обучении системы.
10. **Финальный CTA**: Мотивация пользователя создать ассистента прямо сейчас.
11. **Footer**: Навигация и копирайт.

## Технические детали
- **Фреймворк**: React 19 + Inertia.js v2.
- **Стилизация**: Tailwind CSS v4.
- **Иконки**: `lucide-react`.
- **Компонент**: `resources/js/Pages/Welcome.tsx`.

## Дизайн-решения
- Использована сине-белая цветовая гамма согласно `design_system/colors.md`.
- Применены эффекты размытия (backdrop-blur) для шапки.
- Карточки тарифов имеют hover-эффекты и тени для глубины.
- Адаптивная верстка (Mobile First) для всех секций.
