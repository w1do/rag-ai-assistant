# Маркетплейс чатов (Chats Marketplace)

Документация по реализации страницы `/chats`, представляющей собой каталог доступных ИИ-ассистентов.

## Обзор
Маркетплейс чатов предназначен для демонстрации возможностей платформы и предоставления пользователям доступа к различным специализированным ИИ-ассистентам. Ассистенты разделены по категориям для удобства поиска.

## Основные возможности
- **Каталог ассистентов**: Отображение всех активных ассистентов в виде карточек. Поддерживаются статусы `active` и `ready`.
- **Фильтрация по категориям**:
    - **ИИ чаты**: Общие помощники на базе нейросетей.
    - **Общение**: Боты, адаптированные для диалога и поддержки.
    - **Бизнес**: Ассистенты со знанием специфики деловых процессов (автоматизация, компании).
    - **RAG**: Системы, обученные на конкретных базах знаний.
- **Интеллектуальное распределение**: Категории назначаются автоматически на основе анализа названия и описания ассистента.
- **Поиск**: Поиск по названию и описанию ассистента в реальном времени.
- **Интеграция**: Каждая карточка ведет на страницу публичного чата соответствующего ассистента.

## Техническая реализация
- **Контроллер**: `app/Http/Controllers/MarketplaceController.php`
- **Маршрут**: `/chats` (имя: `chats.index`)
- **React-компонент**: `resources/js/Pages/Chats/Index.tsx`
- **Модель**: `App\Domain\Assistant\Models\Assistant`

## Дизайн
- Выполнен в общем стиле проекта с использованием Tailwind CSS v4.
- Адаптивная сетка (1 колонка на мобильных, 2 на планшетах, 3 на десктопах).
- Использование `lucide-react` для визуализации категорий.
