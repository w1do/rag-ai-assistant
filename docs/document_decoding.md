# Реализация загрузки документов с расшифровкой данных

## Описание
В рамках данной задачи была реализована система загрузки документов (PDF, DOCX, TXT) с автоматическим извлечением текста ("расшифровкой") и сохранением его в базу данных. Это позволяет пользователям видеть содержимое загруженных документов прямо в интерфейсе ассистента.

## Архитектурные изменения (DDD + CQRS)
Логика обработки документов была перенесена из домена `Assistant` в домен `Knowledge` для лучшего разделения ответственности.

### Новые компоненты в домене Knowledge:
- **DTO**: `App\Domain\Knowledge\DTO\UploadKnowledgeDTO` - объект для передачи данных загрузки.
- **Command**: `App\Domain\Knowledge\Commands\UploadKnowledgeCommand` - команда на загрузку документа.
- **Handler**: `App\Domain\Knowledge\Handlers\UploadKnowledgeHandler` - обработчик команды, сохраняющий файл и запускающий фоновую задачу.
- **Job**: `App\Domain\Knowledge\Jobs\ProcessKnowledgeJob` - фоновая задача обработки.
- **Action**: `App\Domain\Knowledge\Actions\ProcessKnowledgeAction` - основная логика извлечения текста (через `LLPhant`) и индексации в векторном хранилище. Включает автоматическое определение кодировки для текстовых файлов, обработку ошибок парсинга PDF и проверку на наличие извлеченного текста.
- **Action**: `App\Domain\Assistant\Actions\IndexAssistantDocumentsAction` - отвечает за разбиение текста на чанки, получение эмбеддингов и сохранение в Qdrant. Теперь включает механизм очистки старых точек перед повторной индексацией.

### Изменения в моделях:
- Модель `Knowledge` теперь сохраняет полный извлеченный текст в поле `content`.
- Поле `metadata` используется для хранения ошибок обработки и технической информации.
- Таблица `chunks` хранит связь между `knowledge_id` и `qdrant_id` для возможности удаления/обновления данных в векторном хранилище.

## Обработка ошибок и кодировок
- **Кодировки**: Реализовано автоматическое определение кодировки (UTF-8, Windows-1251 и др.) для текстовых файлов (.txt).
- **Валидация**: Расширен список поддерживаемых типов в контроллере (pdf, docx, txt, text). Используется правило `extensions` вместо `mimes` для повышения надежности при некорректном определении MIME-типа сервером.
- **Парсинг PDF**: Добавлен маппинг технических ошибок парсера (например, "Unable to find startxref") на понятные пользователю сообщения с рекомендациями.
- **Проверка контента**: Добавлена проверка на пустое содержимое после извлечения текста. Если текст пуст (например, отсканированный документ), знание помечается как `error` с соответствующим уведомлением.
- **Стабильные ID**: Для генерации UUID в Qdrant теперь используется стабильный `sourceName` (имя файла в хранилище), а не абсолютный путь, который может меняться.

## API Документация (Swagger)
Эндпоинт `POST /assistants/{id}/documents` обновлен и теперь включает описание процесса расшифровки данных.

## Инструкция по использованию
1. Перейдите в настройки ассистента.
2. Выберите вкладку "Документы".
3. Загрузите файл (PDF, DOCX или TXT).
4. После обработки в списке источников появится кнопка "Контент", при нажатии на которую отобразится извлеченный текст.
