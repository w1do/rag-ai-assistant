# Исправление ошибки 403 при загрузке аудио (записи голоса)

## Проблема
На продакшене пользователи сталкивались с ошибкой `403 This action is unauthorized` при попытке загрузить аудиозапись (голос) ассистенту.

### Причины
1. **Жесткая проверка баланса**: В `AssistantPolicy` была прописана проверка `balance > 0`, которая выполнялась даже если у пользователя была активная оплаченная подписка. Если пользователь тратил весь баланс на покупку подписки, он лишался возможности загружать аудио.
2. **Отсутствие лимитов в БД**: В некоторых тарифных планах в базе данных отсутствовал ключ `voice_count` в поле `limits`. Политика по умолчанию считала отсутствие ключа как лимит `0`, что приводило к отказу в доступе.

## Решение

### 1. Изменение логики AssistantPolicy
- Проверка баланса (`balance > 0`) теперь выполняется **только если у пользователя нет активной подписки**.
- Если подписка активна, проверяются только лимиты, установленные планом.
- Это изменение затронуло методы: `create`, `addUrl`, `uploadAudio`, `uploadDocument`.

### 2. Улучшение обработки лимитов
- Для `uploadAudio` значение лимита по умолчанию (если оно не задано в плане) изменено с `0` на `-1` (безлимитно). Это предотвращает блокировку при неполной конфигурации планов в БД.

### 3. Обновление BillingSeeder
- В сидер добавлены явные лимиты для всех планов:
    - `voice_count` (голосовые заметки)
    - `links_count` (ссылки на сайты)
    - `document_count` (загрузка документов)
- В плане "Старт" теперь явно разрешено 5 голосовых заметок и 10 ссылок, но запрещена загрузка документов (`document_count = 0`).

## Тестирование
Создан новый набор тестов `tests/Feature/AssistantPolicyTest.php`, который проверяет:
- Разрешение загрузки при балансе 0, но активной подписке.
- Разрешение загрузки по умолчанию при отсутствии ключа лимита в плане.
- Корректную работу проверки баланса для пользователей без подписки.

### Запуск тестов
```bash
./vendor/bin/sail php artisan test tests/Feature/AssistantPolicyTest.php
```

## Изменения в файлах
- `app/Policies/AssistantPolicy.php`: исправление логики авторизации.
- `database/seeders/BillingSeeder.php`: актуализация лимитов в тарифных планах.
- `tests/Feature/AssistantPolicyTest.php`: новые тесты для верификации.
