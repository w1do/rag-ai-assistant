# Настройки и кастомизация ассистента

Документация по параметрам настройки поведения, стиля и брендинга ИИ-ассистентов в BotSync.

## Стили общения (AssistantStyle)
Ассистенты поддерживают четыре предопределенных стиля общения, которые влияют на тон и манеру ответов:

1. **Деловой (Business)**: Профессиональный, сдержанный и конкретный стиль. Используется по умолчанию.
2. **Коммерческий (Commercial)**: Убедительный тон, ориентированный на подчеркивание выгод и призыв к действию.
3. **Грубый (Rude)**: Краткие, дерзкие ответы без лишних любезностей.
4. **Позитивный (Positive)**: Дружелюбный стиль с использованием эмодзи и энергичной подачей.

## Брендинг и контактные данные
Для персонализации ассистента под конкретный бизнес предусмотрены следующие поля:

- **Slug (slug)**: Уникальный человекочитаемый идентификатор ассистента, генерируемый автоматически из названия. Используется для построения URL-адресов.
- **Имя бренда (brand_name)**: Позволяет ассистенту представляться от имени компании.
- **Телефон (phone)**: Контактный номер, который ассистент может предоставлять пользователям.
- **Социальные сети (social)**: Ссылки на Telegram, WhatsApp и другие каналы связи.
- **Приветственное сообщение (welcome_message)**: Текст, который пользователь видит первым при открытии чата.
- **Быстрые действия (actions)**: Массив кнопок с часто задаваемыми вопросами или командами.

## Логика Fallback
Поле `fallback` позволяет задать фразу, которую ассистент произнесет, если в базе знаний (RAG) не будет найдено релевантной информации. Это предотвращает галлюцинации и направляет пользователя к альтернативным способам решения вопроса (например, "Извините, я не нашел информации по этому вопросу, пожалуйста, свяжитесь с оператором").

## Системный промпт
Поле `system` позволяет переопределить базовые инструкции ассистента, задавая уникальную роль или специфические ограничения. Это сообщение добавляется в начало диалога с моделью.

## Техническая реализация
- **Перечисление**: `app/Domain/Assistant/Enums/AssistantStyle.php`
- **Модель**: `app/Domain/Assistant/Models/Assistant.php`
- **Логика промптов**: `app/Domain/Chat/Queries/AskAssistantQuery.php` (метод `buildSystemMessageTemplate`)
