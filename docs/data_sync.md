# Интеграция и синхронизация данных (DataSync)

Документация по компоненту и функционалу интеграции BotSync с внешними системами и CRM.

## Обзор
Модуль DataSync предназначен для автоматизации процесса наполнения базы знаний RAG-системы данными из существующих корпоративных систем. Это позволяет ИИ-ассистенту всегда обладать актуальной информацией без ручного обновления документов.

## Ключевые возможности
- **Интеграция с CRM**: Поддержка популярных систем, таких как Bitrix24 и amoCRM.
- **Закрытые системы**: Возможность подключения к внутренним базам данных и закрытым API через защищенные каналы.
- **Личные кабинеты**: Синхронизация данных из пользовательских профилей и личных кабинетов.
- **Автопулинг (Auto-pooling)**: Регулярный автоматический сбор и индексация новых данных в векторное хранилище (Qdrant).
- **Безопасность**: Поддержка On-premise решений и шифрование данных при передаче.

## Техническая реализация
- **React-компонент**: `resources/js/Components/DataSync.tsx`.
- **Интерфейс**: Использование иконок `lucide-react` (`Database`, `RefreshCw`, `Lock`, `Zap`, `ShieldCheck`) для визуализации процессов.
- **Стилизация**: Tailwind CSS v4 с использованием градиентов и сеточных макетов (grid).

## Использование на лендинге
Компонент интегрирован в главную страницу (`Welcome.tsx`) и служит для демонстрации B2B-возможностей платформы потенциальным клиентам.
