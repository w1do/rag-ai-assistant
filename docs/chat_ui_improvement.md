# Улучшение пользовательского интерфейса чата (Chat UI Improvement)

## Обзор
В рамках данной задачи был переработан интерфейс встроенного чата (`ShareChat.tsx`) и логика формирования ответов ассистента для обеспечения «красивого стиля», структурированности и удобства восприятия информации.

## Ключевые изменения

### 1. Форматирование ответов (Backend)
- **Системный промпт**: В класс `AskAssistantQuery` добавлены строгие инструкции для ИИ по использованию Markdown.
    - Обязательное использование **жирного шрифта** для акцентов.
    - Использование маркированных и нумерованных списков для перечислений.
    - Разделение текста на короткие абзацы.
    - Использование подзаголовков (`###`) для длинных ответов.
- **Стили общения**: Сохранены и интегрированы с новыми правилами форматирования.
- **Источники (Sources)**: Восстановлена передача источников данных в ответе публичного чата.

### 2. Пользовательский интерфейс (Frontend)
- **Кастомный Markdown**: Настроен рендеринг Markdown в `ShareChat.tsx`. Теперь заголовки, списки и выделения отображаются с правильными отступами и цветами.
- **Дизайн пузырей**:
    - Сообщения ассистента получили иконку робота и мягкую тень.
    - Сообщения пользователя выделены насыщенным цветом и имеют индикатор «Я».
    - Добавлены анимации появления сообщений (`animate-in`).
- **Шапка чата**: Реализован современный заголовок с градиентным аватаром, индикатором «Онлайн» и кнопками действий.
- **Поле ввода**: Улучшен дизайн инпута, добавлена иконка вложения (декоративная) и динамическая кнопка отправки с анимацией.
- **Отображение источников**: Под ответом ассистента теперь выводятся компактные теги со ссылками на использованные документы или сайты.

## Архитектура (DDD)
Изменения внесены в соответствии с архитектурой Domain-Driven Design:
- **Domain**: Логика формирования промпта находится в `app/Domain/Chat/Queries/AskAssistantQuery.php`.
- **Infrastructure**: Работа с AI клиентами инкапсулирована в `app/Infrastructure/AI`.
- **Application/Interface**: Контроллеры и Inertia-компоненты отвечают только за отображение и передачу данных.

## Тестирование
- Обновлены и успешно пройдены Unit-тесты для проверки системного промпта (`AssistantPromptTest.php`).
- Исправлены Feature-тесты для публичного чата (`PublicChatTest.php`).
- Визуально проверена корректность отображения Markdown-элементов.
