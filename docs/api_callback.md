# API Callback (Дообучение ассистента)

Этот эндпоинт позволяет клиентам отправлять подготовленные данные (вопросы и ответы) напрямую для индексации в базе знаний ассистента.

## Эндпоинт

`POST /api/v1/callback`

## Формат запроса (JSON)

| Поле | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `assistant_id` | `integer` | Да | ID ассистента в системе |
| `name` | `string` | Да | Название источника знаний |
| `chunks` | `array` | Да | Массив объектов с произвольными данными |
| `chunks[]` | `object` | Да | Объект с произвольным набором полей (ключ-значение) |

### Примеры запроса

#### 1. Вопросы и ответы (Классический формат)
```json
{
  "assistant_id": 1,
  "name": "FAQ по пиццерии",
  "chunks": [
    {
      "question": "Какую пиццу вы готовите?",
      "answer": "Мы готовим большую и тонкую пиццу на дровах."
    }
  ]
}
```

#### 2. Информация о товарах (Произвольный формат)
```json
{
  "assistant_id": 1,
  "name": "Каталог товаров",
  "chunks": [
    {
      "title": "iPhone 15",
      "price": "999$",
      "description": "Последняя модель смартфона от Apple"
    },
    {
      "title": "Samsung S24",
      "price": "899$"
    }
  ]
}
```

## Ответы

### Успешный ответ (200 OK)

```json
{
  "success": true,
  "message": "Данные успешно получены и проиндексированы",
  "assistant_id": 1,
  "knowledge_id": 42
}
```

### Ошибка валидации (422 Unprocessable Entity)

```json
{
  "message": "The assistant id field is required.",
  "errors": {
    "assistant_id": ["The assistant id field is required."]
  }
}
```

### Внутренняя ошибка (500 Internal Server Error)

```json
{
  "success": false,
  "message": "Ошибка при индексации данных: [Текст ошибки]"
}
```

## Обработка данных

1. Система создает новую запись в таблице `knowledge` с типом `api`.
2. Каждая пара вопрос-ответ объединяется в текстовый блок.
3. Блоки преобразуются в векторные эмбеддинги.
4. Данные сохраняются в коллекцию Qdrant, связанную с ассистентом.
5. Ассистент сразу начинает использовать эти данные для ответов в чате.
