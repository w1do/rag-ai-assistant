# Редизайн карточек статистики Dashboard

## Описание
Произведен полный редизайн карточек статистики в личном кабинете для придания им более современного и "премиального" вида в соответствии с дизайн-системой BotSync.

## Изменения

### 1. Компоненты (Frontend)
- **Создан `StatCard`**: Новый переиспользуемый компонент в `resources/js/Components/Dashboard/StatCard.tsx`.
  - **Фоновые иконки**: Добавлены крупные полупрозрачные иконки (`opacity-[0.03]`), которые масштабируются и смещаются при наведении (`group-hover:scale-150`).
  - **Градиенты**: 
    - Добавлен радиальный градиент фона при наведении.
    - Использован `text-gradient` для отображения числовых значений.
  - **Анимированный бордер**: Реализован эффект переливающегося бордера (`shimmer`) при наведении, использующий градиент от `primary-color` к `white-color`.
  - **Интерактивность**: Добавлена тень (glow) вокруг иконки и плавные переходы для всех элементов.

### 2. Стили (CSS)
- **`resources/css/app.css`**:
  - Добавлена ключевая анимация `@keyframes shimmer` для эффекта перелива.
  - Исправлена переменная `--radius-three`: значение изменено на `2px` по требованию пользователя (вместо исходных `24px` из `DESIGN_UI.md`). Это сделало карточки более строгими.

### 3. Страницы
- **`resources/js/Pages/Dashboard.tsx`**:
  - Старая верстка карточек заменена на компонент `StatCardComponent`.
  - Добавлены соответствующие ссылки (`href`) для каждой категории статистики (Ассистенты, Диалоги, База знаний).
  - Внедрена WOW-анимация появления карточек с каскадной задержкой.

## Дизайн-принципы (DESIGN_UI)
- **Цвета**: Использование `--primary-color` (#DFFF00) и `--primary-rgb-12`.
- **Скругления**: 2px (`rounded-three`).
- **Шрифты**: `Unbounded` для значений и `DM Sans` для подписей.
- **Эффекты**: Двойной фон для градиентного бордера (`padding-box` + `border-box`).

## Тестирование
- Визуальная проверка эффектов наведения (hover).
- Проверка адаптивности (grid-cols-1 на мобильных, md:grid-cols-3 на десктопах).
- Проверка корректности переходов по ссылкам.
