# Обновление Дизайн-системы: Радиусы и Заголовки

## Переменные радиусов (Border Radius)
Все радиусы скругления теперь вынесены в CSS-переменные в `resources/css/app.css` для глобального управления из одного места.

### Основные токены
| Переменная | Значение | Описание |
|------------|----------|----------|
| `--radius-one` | `5px` | Малые элементы (бейджы, алерты) |
| `--radius-two` | `15px` | Средние блоки, кнопки, инпуты |
| `--radius-three` | `2px` | **Текущий выбор для карточек** (строгий стиль) |
| `--radius-four` | `24px` | Большие блоки (исходный премиальный стиль) |
| `--radius-full` | `9999px` | Полное скругление (pill) |

### Глобальный маппинг Tailwind
Стандартные классы Tailwind (`rounded-lg`, `rounded-xl` и т.д.) теперь привязаны к этим переменным:
- `rounded-sm`, `rounded-xs` -> `--radius-one`
- `rounded-md`, `rounded-lg`, `rounded-xl` -> `--radius-two`
- `rounded-2xl`, `rounded-3xl` -> `--radius-four`

Это позволяет изменить скругление во всем приложении, просто поменяв значение одной переменной.

## Компонент SectionHeader
Добавлен новый компонент `resources/js/Components/UI/SectionHeader.tsx` для визуального разделения секций.

### Особенности
- **Декоративная линия**: Содержит градиентную линию с анимированным бликом (`shimmer`).
- **Интерактивность**: Поддерживает действие (ссылку/кнопку) справа с hover-эффектом подчеркивания и анимацией иконки.
- **Консистентность**: Автоматически использует системные цвета и шрифты.

### Пример использования
```tsx
<SectionHeader 
    title="Ассистенты" 
    icon={Sparkles}
    href={route('assistants.create')}
    linkText="Добавить нового"
    linkIcon={Plus}
/>
```
