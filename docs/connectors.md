# Раздел "Коннекторы"

Этот раздел предназначен для управления внешними платформами публикации (VK, Telegram, MAX, VC.ru) и привязки к ним ассистентов. Это позволяет ассистентам выполнять постинг на основе Rag-данных.

## Структура DDD

Реализация следует паттерну DDD + CQRS и расположена в домене `Connector`.

### Domain: `App\Domain\Connector`

- **Models**:
  - `Connector`: Основная сущность коннектора (название, описание, иконка, статус, настройки API).
  - `ConnectorAssistant`: Модель связи между коннекторами и ассистентами.
  - `ConnectorContent`: История публикаций через коннектор (текст, статус).
- **Commands**:
  - `AttachAssistantCommand`: Команда для привязки ассистента к коннектору.
- **Handlers**:
  - `AttachAssistantHandler`: Обработчик привязки ассистента. Использует `syncWithoutDetaching`.
- **Queries**:
  - `GetConnectorsListQuery`: Получение списка доступных коннекторов с подгруженными ассистентами.

## HTTP Layer

- **Controller**: `App\Http\Controllers\Connector\ConnectorController`
  - `index`: Отображение страницы списка коннекторов. Передает `connectors` и `assistants` (всех ассистентов пользователя).
  - `attachAssistant`: Обработка формы подключения ассистента.

## Frontend

Страница реализована на React 19 с использованием Inertia.js v2 и Tailwind CSS v4.

- **Путь**: `resources/js/Pages/Connectors/Index.tsx`
- **Функционал**:
  - Интерактивные карточки коннекторов с поддержкой темных иконок.
  - Динамическое модальное окно для выбора ассистента.
  - Список подключенных ассистентов отображается прямо на карточке в виде бейджей.

## База данных

Миграции:
- `connectors`: Базовая информация о платформах.
- `connector_assistants`: Связь many-to-many между коннекторами и ассистентами.
- `connector_contents`: Лог публикаций.

Сидер: `ConnectorSeeder` наполняет базу базовыми коннекторами (VK, Telegram, MAX, VC.ru).
