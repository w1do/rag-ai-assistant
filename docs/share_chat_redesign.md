# Редизайн публичного чата (Share Chat)

## Обзор
Публичная страница чата (`/share-chat/{id}`) была полностью переработана в соответствии с новой дизайн-системой BotSync.

## Ключевые изменения

### Визуальный стиль (UI)
- **Цветовая схема**: Переход на темную тему BotSync (`#0A0708`) с акцентным неоново-лаймовым цветом (`#DFFF00`).
- **Типографика**: 
  - Заголовки используют шрифт **Unbounded**.
  - Основной текст использует шрифт **DM Sans**.
- **Компоненты**:
  - **Пузыри сообщений**: Теперь имеют радиус скругления **24px** (`rounded-three`).
  - **Сообщения пользователя**: Выделены акцентным цветом (`bg-primary-color`) с контрастным черным текстом.
  - **Сообщения ассистента**: Используют темный фон (`bg-background-one`) с тонкой границей (`border-border-color-one`) для лучшей читаемости.
  - **Шапка**: Полупрозрачный фон с эффектом размытия (`backdrop-blur`) и обновленным аватаром ассистента.

### Брендинг
- Удалены упоминания "NeuralFlow Engine".
- Добавлен копирайт **BotSync** в футере страницы.
- Анимация обработки запроса теперь отображает статус "BotSync обработка...".

### Технические детали
- Обновлена переменная `--radius-three` в `app.css` до корректного значения **24px**.
- Стили приведены в соответствие с токенами из `DESIGN_UI.md`.
- Выполнена сборка фронтенда для применения изменений в продакшене.

## Файлы
- `resources/js/Pages/ShareChat.tsx` — основной компонент страницы.
- `resources/css/app.css` — обновлены CSS-переменные.
- `design_system/sizes.md` — актуализированы данные о радиусах.
