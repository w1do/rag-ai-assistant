# Техническая документация AI Assistant RAG System

## Архитектура: DDD + CQRS

Проект реализован с использованием подходов Domain-Driven Design (DDD) и Command Query Responsibility Segregation (CQRS).

### Структура каталогов
Вся бизнес-логика вынесена в директорию `app/Domain`, разделенную на домены:

- **Assistant**: Управление ассистентами, документами и чанками.
- **Chat**: История переписки и логика взаимодействия с ассистентом.
- **Knowledge**: Логика управления базой знаний и генерации контента на основе внешних источников.
- **Shared**: Общие сервисы, такие как RAG-пайплайн.

### Слои (CQRS)
Внутри каждого домена выделены следующие слои:

- **Models**: Eloquent-модели, специфичные для домена.
- **Actions (Commands)**: Классы, выполняющие операции записи (создание, обновление, удаление, запуск процессов).
- **Queries**: Классы, выполняющие только чтение данных для отображения в UI.
- **Jobs**: Фоновые задачи домена.

Пример использования в контроллере:
```php
public function store(Request $request, StoreAssistantAction $action): RedirectResponse
{
    // Валидация в контроллере
    $validated = $request->validate([...]);
    
    // Выполнение бизнес-логики через Action
    $action->execute(auth()->user(), $validated);

    return redirect()->route('assistants.index');
}
```

## AI Интеграция и RAG

### LLPhant
Основной фреймворк для реализации RAG (Retrieval-Augmented Generation). Используется для:
- Чтения документов (PDF, Docx, TXT).
- Генерации эмбеддингов.
- Поиска сходства в векторной БД Qdrant.
- Генерации ответов (QA).

### Векторная БД: Qdrant
Используется для хранения векторов текста. Для каждого ассистента создается отдельная коллекция `assistant_{id}` с размерностью 1536 (OpenAI embeddings).

### Интеграция с PolzaAi
Система поддерживает работу с PolzaAi (и другими OpenAI-совместимыми провайдерами).
Настройка производится в `.env` через переменные:
- `OPENAI_API_KEY`: Ваш API ключ.
- `OPENAI_BASE_URL`: Базовый URL провайдера (например, `https://api.polzai.ru/v1`).

### Фоновые процессы
Длительные операции вынесены в очереди (Laravel Horizon):
1. **ProcessDocumentJob**: Чтение файла, чанкинг, генерация эмбеддингов и сохранение в Qdrant.
2. **TranscribeVoiceJob**: Транскрипция аудио через Whisper и последующая индексация.
3. **GenerateKnowledgeJob**: Парсинг текста с URL и генерация записи в базу знаний через LLM.

## Переменные окружения (.env)
Все чувствительные данные вынесены в `.env`:
- `QDRANT_HOST`, `QDRANT_PORT`: Настройки подключения к векторному хранилищу.
- `OPENAI_API_KEY`, `OPENAI_BASE_URL`: Настройки AI-провайдера.
